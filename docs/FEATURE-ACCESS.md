# Universal feature access

Better CaptionKeep is one product. Every feature included in a published build is available to every user without payment, activation, subscription, license key, or feature-tier check.

The extension contains no Free/Pro split, commercial entitlement state, billing integration, or activation service. Development, UAT, and production use different identities only to preserve the governed release lifecycle; those identities do not unlock different paid capabilities.

Organizational policy can still disable or constrain features for security, privacy, retention, and compliance. Provider-controlled capabilities can still require user authorization, administrator consent, compatible browser support, or an eligible Microsoft 365 tenant. Those operational controls are not commercial feature tiers.

Future features follow the same rule unless the product owner explicitly changes this decision through the normal Dev, UAT, and production lifecycle.
