# Safari groundwork archive

Lead decision: October 14, 2026. Safari is removed completely from active
Better CaptionKeep 6.0. Chrome, Edge, Brave, Firefox, and Opera remain the five
separately tested release targets. Safari support can be reconsidered only in a
later major version; no future version or delivery date is promised.

This directory preserves recoverable historical preparation. Nothing here is
an active 6.0 build, test, support, certification, or Store-submission gate.

- [Original Mac test handoff](MAC-TEST-HANDOFF-6.0.md)
- [Original cloud testing research](SAFARI-CLOUD-TEST-OPTION-6.0.md)

Historical dated reviews retain their original findings with a superseded-scope
notice. Old external ZIPs are not current release artifacts. Any later revival
requires fresh platform research, adaptation, package identity, native/helper
acceptance, and real browser/provider evidence; historical work is not a pass.
