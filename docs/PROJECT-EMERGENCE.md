# Better CaptionKeep standalone product record

On September 21, 2026, `Mr-GraphnStaff/better-captionkeep` left the
`Zerg00s/Live-Captions-Saver` GitHub fork network and became a standalone
repository.

This changes the repository relationship, not the project's history or legal
obligations. Better CaptionKeep originated from Live-Captions-Saver, and the
original MIT copyright, permission notice, commit history, and attribution
remain preserved.

## Independent product boundary

Better CaptionKeep owns its product direction, provider-adapter architecture,
release process, privacy controls, enterprise deployment, testing evidence,
and roadmap. Microsoft Teams and Google Meet are the supported providers in
the published 5.0.0 release. Additional providers must pass their own evidence,
privacy, compatibility, automated-validation, and live-UAT gates before being
described as released support.

Future contributors fork Better CaptionKeep and submit changes to this
repository. The former parent project remains an attributed historical origin,
not the development upstream for current releases.

## Preservation and governance

Before detachment, maintainers created and verified a complete Git mirror, a
bundle containing all local refs, a GitHub metadata export, and a copy of the
exact published v5.0.0 artifact. GitHub preserved the live issues, pull
requests, release, rulesets, branches, and environment during detachment.

The standalone repository continues to require protected production and
release branches, complete release-candidate validation, immutable reviewed
artifacts, controlled Store promotion, privacy-preserving evidence, and
explicit product-owner release decisions.
