# Public documentation

This directory is reserved for documentation approved for publication with Better CaptionKeep.

Documents under `docs/prv/` are local internal product, architecture, and security-planning records. That directory is excluded from Git and must not be referenced by public release notes, Store submissions, packaged extension artifacts, or public documentation.

Existing tracked files directly under `docs/` predate this split. Move them here only through a dedicated documentation change that classifies each file and updates every repository link.
