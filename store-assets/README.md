# Microsoft Edge Store assets

This directory preserves the exact listing artwork used for each public release. These files are Partner Center collateral and are not included in the extension ZIP.

## 5.0

- `5.0/small-promotional-tile.png` — 440 x 280
- `5.0/large-promotional-tile.png` — 1400 x 560
- `5.0/01-live-capture.png` — 1280 x 800

The 5.0 artwork names Microsoft Teams and Google Meet consistently with the submitted package, privacy disclosure, and Store description. Future artwork changes must be reviewed alongside Store metadata and preserved under the corresponding version directory before submission.
