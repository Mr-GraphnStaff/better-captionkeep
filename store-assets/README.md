# Browser store assets

This directory preserves the exact listing artwork used for each public release. These files are store-listing collateral and are not included in the extension ZIP.

## 5.0

- `5.0/small-promotional-tile.png` — 440 x 280
- `5.0/large-promotional-tile.png` — 1400 x 560
- `5.0/01-live-capture.png` — 1280 x 800

The 5.0 artwork names Microsoft Teams and Google Meet consistently with the package, privacy disclosure, and store description. The dimensions satisfy the Chrome Web Store's screenshot, small promotional tile, and marquee tile slots. Confirm each image reflects the Chrome candidate during Chrome UAT before uploading it. Future artwork changes must be reviewed alongside store metadata and preserved under the corresponding version directory before submission.
