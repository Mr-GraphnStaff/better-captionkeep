# Better CaptionKeep 5.4 Store artwork

These assets use synthetic meeting content and the current 5.4 interaction
model. They contain no real participant, tenant, meeting, transcript, token, or
customer data.

The screenshots cover verified product behavior: three supported meeting
platforms, explicit source controls, On the Fly selected-evidence handoff,
review-before-copy assistant opening, and customer-controlled enterprise
boundaries. On the Fly does not return an answer to the extension or submit a
prompt automatically.
Scribble remains the Better CaptionKeep icon. The sphere and the line
**A DAF-TECH Product** identify the parent brand.

`source.html` is the deterministic artwork source for the five-image Store
story. Render the small tile at 440 x 280 with `?promo=small`, and the
large tile at 1400 x 560 with `?promo=large`.
